# SynPathMR: Turing Test

Interactive Turing Test evaluation for the **SynPathMR** 3D brain tumor MRI synthesis framework.

Viewers evaluate multiple morphology cases and attempt to distinguish authentic clinical ground truth MRIs from synthetic tumor generation (SynPathMR Anchor Tokens, noise baselines, and unconditioned controls).
